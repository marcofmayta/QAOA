Guía de implementación

Cómo llevar QAOA de la teoría al circuito compilado y al hardware real, con ejemplos de código y criterios para elegir parámetros y compuertas.

1. Optimización de parámetros

El bucle clásico es, en muchas aplicaciones, el cuello de botella real: cada evaluación de \( E(\vec\gamma,\vec\beta) \) requiere ejecutar el circuito muchas veces. Para un observable de varianza finita, estimar su media con error estadístico \( \epsilon \) requiere un número de disparos del orden de \(\operatorname{Var}(C)/\epsilon^2\) para un error estándar \(\epsilon\). La varianza, la confianza exigida y el protocolo de medición importan.

Métodos basados en gradiente

  • Regla de desplazamiento de parámetros: para una rotación \( e^{-i\theta P/2} \), con \( P^2=I \), la derivada del valor esperado ideal, respecto del ángulo de esa puerta, se obtiene con dos evaluaciones: \( \partial_\theta E = \tfrac{1}{2}[E(\theta+\tfrac{\pi}{2}) - E(\theta-\tfrac{\pi}{2})] \). Con mediciones finitas se obtiene un estimador estadístico. Si un parámetro aparece en varias compuertas, se suman sus contribuciones con la regla de la cadena; desplazar toda la capa no suele bastar.
  • Diferencias finitas: aproximación simple pero propensa al ruido estadístico de disparos.
  • Gradiente por diferenciación adjunta: eficiente en simuladores, pero limitado por memoria en \( n \) grande.

Alternativas para la optimización

  • COBYLA: método sin derivadas usado en problemas con pocos parámetros.
  • Nelder-Mead: simple pero escala mal con \( p \).
  • SPSA: aproximación estocástica del gradiente, útil cuando los disparos son limitados.
  • CMA-ES y variantes: métodos poblacionales que pueden explorar paisajes multimodales; el costo depende del presupuesto y la instancia.

Optimización basada en CVaR

En lugar de minimizar \( \mathbb{E}[C] \), se minimiza el valor en riesgo condicional sobre la fracción \( \alpha \) de mejores muestras:

$$ \mathrm{CVaR}_\alpha = \max_{t} \left\{ t - \frac{1}{\alpha} \mathbb{E}\bigl[(t - C)^+\bigr] \right\} $$

Para \(0<\alpha\leq1\), esta expresión corresponde a la media de la cola inferior de costos (repartiendo la masa de probabilidad en el umbral si hay empates), con \(u^+=\max(u,0)\). Su minimización prioriza las mejores muestras, sin garantizar una mejora universal. Barkoutsos et al. (2020).

Con muestras equiprobables ordenadas \(c_{(1)}\leq\cdots\leq c_{(N)}\), usa \(m=\lfloor\alpha N\rfloor\) y \(r=\alpha N-m\):

$$ \widehat{\mathrm{CVaR}}_\alpha=\frac{\sum_{k=1}^{m}c_{(k)}+r c_{(m+1)}}{\alpha N} $$

Si \(r=0\), el término fraccionario se omite, incluso cuando \(m=N\). No se debe redondear la cantidad de muestras sin especificar una convención.

Estrategias de inicialización y transferencia

  • Para MaxCut no ponderado, inicialización aleatoria uniforme en \( [0,2\pi)\times[0,\pi) \).
  • Interpolación de los perfiles de ángulos desde \( p-1 \) hacia \( p \). Añadir una capa con ángulos cero conserva el estado previo, pero no equivale a interpolar.
  • Transferencia entre instancias: reutilizar \( (\vec\gamma^*,\vec\beta^*) \) de problemas similares.

2. Compilación de circuitos

El problema de MaxCut definido en un grafo \( G \) requiere interacciones ZZ entre pares de qubits. Si una arista del problema no está disponible físicamente, el compilador necesita enrutamiento, por ejemplo mediante SWAPs, lo que puede aumentar el número de compuertas de dos qubits y la profundidad.

Coste de SWAPs

En una base de CNOTs, un SWAP puede descomponerse en 3 CNOTs. Para ejecutar un ZZ entre dos qubits a distancia \( d \) en la topología del hardware, se necesitan aproximadamente \( 3(d-1) \) CNOTs de enrutamiento más 2 CNOTs para el propio ZZ, si no se restaura la disposición inicial. El costo real depende del compilador y del conjunto de compuertas nativas.

Compilación en una cadena lineal

Si el grafo de interacción no es un subgrafo de la conectividad física, reordenar los qubits no hace locales todas sus aristas. Una red de SWAPs permite ejecutar las interacciones manteniendo el Hamiltoniano original. Omitir aristas cambia el problema que se optimiza.

Profundidad efectiva

Si todas las capas tienen costos de compilación similares y se omiten la preparación y la medición, la profundidad se aproxima como:

$$ D \approx p \cdot \bigl( D_C^{\text{enrutado}} + D_B \bigr) $$

con \( D_C^{\text{enrutado}} \) la profundidad del bloque de costo incluyendo enrutamiento, y \( D_B \) la profundidad del bloque de mezcla (una capa de rotaciones \( R_X \) en paralelo).

3. Manejo de restricciones

Penalización y mezcladores adaptados

Los métodos de penalización modifican el Hamiltoniano de costo para una igualdad \(g(x)=0\), añadiendo \(\lambda g(x)^2\). El mezclador X puede recorrer estados no factibles. La probabilidad de obtener soluciones válidas depende de los parámetros y de la penalización; no necesariamente disminuye en todos los casos. Una desigualdad requiere otra codificación, por ejemplo una variable de holgura. Los mezcladores que preservan la factibilidad restringen la evolución al subespacio factible desde el inicio.

Estado inicial factible

Un mezclador que conserva las restricciones necesita un estado inicial factible. También debe conectar las soluciones que interesa explorar; conservar la factibilidad por sí solo no asegura esa conectividad.

Variables de holgura

Una desigualdad puede convertirse en igualdad mediante una variable de holgura no negativa, codificada en binario. Las igualdades no requieren holgura por sí mismas. Si la holgura toma valores enteros entre cero y una cota, el número de qubits adicionales es \( \lceil \log_2(\text{cota}+1) \rceil \) por restricción.

4. Cómo programar QAOA

El procedimiento consiste en codificar el objetivo, preparar el estado, aplicar las capas de costo y mezcla, y ajustar los ángulos con un optimizador clásico. Este ejemplo busca soluciones de MaxCut en un ciclo de cuatro vértices.

Python: ejemplo completo con Qiskit

python -m pip install qiskit numpy scipy

Se usa simulación ideal del vector de estado para optimizar y se toman 1024 muestras al final. Con \(H_C=\sum (I-Z_iZ_j)/2\), la puerta de costo es rzz(-gamma) y la mezcla es rx(2*beta). El optimizador minimiza el negativo del corte esperado.

import numpy as np
from scipy.optimize import minimize
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector

aristas = [(0, 1), (1, 2), (2, 3), (3, 0)]
costos = np.array([sum(((x >> i) & 1) != ((x >> j) & 1)
                       for i, j in aristas) for x in range(16)])

def circuito(parametros):
    gamma, beta = parametros  
    qc = QuantumCircuit(4)
    qc.h(range(4))
    for i, j in aristas:
        qc.rzz(-gamma, i, j)  
    qc.rx(2 * beta, range(4))
    return qc

def objetivo(parametros):
    probabilidades = Statevector.from_instruction(circuito(parametros)).probabilities()
    return -float(probabilidades @ costos)  

if __name__ == "__main__":
    resultado = minimize(objetivo, [0.5, 0.3], method="COBYLA",
                         options={"maxiter": 200})
    print("Corte esperado:", -resultado.fun)
    estado = Statevector.from_instruction(circuito(resultado.x))
    estado.seed(42)
    muestras = estado.sample_counts(1024)
    mejor = max(muestras, key=lambda bits: costos[int(bits, 2)])
    print("Mejor partición muestreada:", mejor, "corte:", costos[int(mejor, 2)])

5. Calculadora de profundidad de circuito

Modelo simplificado del número de compuertas de dos qubits y de la profundidad para MaxCut sobre un grafo completo \( K_n \) en distintas topologías de hardware. Los factores de enrutamiento son estimaciones geométricas, no mediciones de un circuito compilado.

Se estiman \( p|E|(3\bar d-1) \) CNOTs, más \( pn \) rotaciones X. La profundidad incluye las rotaciones Z y omite preparación y medición; la estimación ignora conflictos de rutas y no sustituye la compilación para un dispositivo concreto.

6. Un problema, cinco implementaciones más

Todos los ejemplos usan el ciclo 0–1–2–3–0 y maximizan el corte esperado. Son simulaciones ideales. Los ejemplos Python usan COBYLA; JavaScript y Julia buscan en una malla, por lo que sus ángulos y precisión pueden diferir.

PennyLane · Python

Evaluación exacta de las cuatro correlaciones ZZ. Admite pares de parámetros para varias capas.

python -m pip install pennylane scipy numpy
import numpy as np
import pennylane as qml
from scipy.optimize import minimize

ARISTAS = [(0, 1), (1, 2), (2, 3), (3, 0)]
dispositivo = qml.device("default.qubit", wires=4, shots=None)

@qml.qnode(dispositivo)
def correlaciones(parametros):
    for i in range(4):
        qml.Hadamard(wires=i)
    for gamma, beta in np.asarray(parametros).reshape(-1, 2):
        for i, j in ARISTAS:
            qml.IsingZZ(-gamma, wires=[i, j])
        for i in range(4):
            qml.RX(2 * beta, wires=i)
    return tuple(qml.expval(qml.PauliZ(i) @ qml.PauliZ(j))
                 for i, j in ARISTAS)

def corte(parametros):
    return float(sum((1 - zz) / 2 for zz in correlaciones(parametros)))

if __name__ == "__main__":
    resultado = minimize(lambda x: -corte(x), [0.5, 0.3],
                         method="COBYLA", options={"maxiter": 200})
    print("Corte esperado:", corte(resultado.x))

Cirq · Python

La rotación ZZ se descompone como CNOT–RZ(−γ)–CNOT. Se evalúan observables para evitar confusiones de orden de bits.

python -m pip install cirq-core scipy numpy
import numpy as np
import cirq
from scipy.optimize import minimize

ARISTAS = [(0, 1), (1, 2), (2, 3), (3, 0)]
qubits = cirq.LineQubit.range(4)
simulador = cirq.Simulator(dtype=np.complex128)

def circuito(parametros):
    qc = cirq.Circuit(cirq.H.on_each(*qubits))
    for gamma, beta in np.asarray(parametros).reshape(-1, 2):
        for i, j in ARISTAS:
            qc.append(cirq.CNOT(qubits[i], qubits[j]))
            qc.append(cirq.rz(-gamma)(qubits[j]))
            qc.append(cirq.CNOT(qubits[i], qubits[j]))
        qc.append(cirq.rx(2 * beta).on_each(*qubits))
    return qc

def corte(parametros):
    observables = [cirq.Z(qubits[i]) * cirq.Z(qubits[j]) for i, j in ARISTAS]
    valores = simulador.simulate_expectation_values(
        circuito(parametros), observables, qubit_order=qubits)
    return float(sum((1 - zz.real) / 2 for zz in valores))

if __name__ == "__main__":
    resultado = minimize(lambda x: -corte(x), [0.5, 0.3],
                         method="COBYLA", options={"maxiter": 200})
    print("Corte esperado:", corte(resultado.x))

NumPy · Python

Simulación explícita de amplitudes. Incluye la fase de costo completa, sin omitir su constante.

python -m pip install numpy scipy
import numpy as np
from scipy.optimize import minimize

ARISTAS = [(0, 1), (1, 2), (2, 3), (3, 0)]
COSTOS = np.array([sum(((x >> i) & 1) != ((x >> j) & 1)
                      for i, j in ARISTAS) for x in range(16)])

def estado(parametros):
    psi = np.ones(16, dtype=complex) / 4
    for gamma, beta in np.asarray(parametros).reshape(-1, 2):
        psi *= np.exp(-1j * gamma * COSTOS)
        c, s = np.cos(beta), np.sin(beta)
        for q in range(4):
            for x in range(16):
                if x & (1 << q):
                    continue
                y = x | (1 << q)
                a, b = psi[x], psi[y]
                psi[x], psi[y] = c * a - 1j * s * b, c * b - 1j * s * a
    return psi

def corte(parametros):
    return float(np.abs(estado(parametros)) ** 2 @ COSTOS)

if __name__ == "__main__":
    resultado = minimize(lambda x: -corte(x), [0.5, 0.3],
                         method="COBYLA", options={"maxiter": 200})
    print("Corte esperado:", corte(resultado.x))

JavaScript · sin bibliotecas

Búsqueda en una malla de 80 × 80 puntos para una capa. Puede ejecutarse aquí en el navegador.

node -e "const q = require('./ejemplos/qaoa_javascript.js'); console.log(q.buscar())"

(function (global) {
  "use strict";
  const aristas = [[0, 1], [1, 2], [2, 3], [3, 0]];
  const costos = Array.from({length: 16}, (_, x) =>
    aristas.reduce((c, [i, j]) => c + (((x >> i) & 1) !== ((x >> j) & 1)), 0));
  function corte(gamma, beta) {
    const re = new Float64Array(16), im = new Float64Array(16);
    for (let x = 0; x < 16; x++) {
      re[x] = Math.cos(gamma * costos[x]) / 4;
      im[x] = -Math.sin(gamma * costos[x]) / 4;
    }
    const c = Math.cos(beta), s = Math.sin(beta);
    for (let q = 0; q < 4; q++) for (let x = 0; x < 16; x++) {
      if (x & (1 << q)) continue;
      const y = x | (1 << q), ar = re[x], ai = im[x], br = re[y], bi = im[y];
      re[x] = c * ar + s * bi; im[x] = c * ai - s * br;
      re[y] = c * br + s * ai; im[y] = c * bi - s * ar;
    }
    return costos.reduce((total, costo, x) => total + costo * (re[x] ** 2 + im[x] ** 2), 0);
  }
  function buscar(pasos = 80) {
    if (!Number.isInteger(pasos) || pasos < 2 || pasos > 500) throw new RangeError("Usa entre 2 y 500 pasos");
    let mejor = {valor: -Infinity, gamma: 0, beta: 0};
    for (let i = 0; i < pasos; i++) for (let j = 0; j < pasos; j++) {
      const gamma = 2 * Math.PI * i / pasos, beta = Math.PI * j / pasos;
      const valor = corte(gamma, beta);
      if (valor > mejor.valor) mejor = {valor, gamma, beta};
    }
    return mejor;
  }
  global.QAOAEjemplo = {corte, buscar};
  if (typeof module !== "undefined") module.exports = global.QAOAEjemplo;
})(globalThis);

Julia · sin paquetes externos

Mismo simulador y búsqueda discreta que en JavaScript. Requiere Julia; no necesita Yao ni instalación de paquetes.

julia ejemplos/qaoa_julia.jl

const ARISTAS = [(0, 1), (1, 2), (2, 3), (3, 0)]
const COSTOS = [sum(((x >> i) & 1) != ((x >> j) & 1)
                    for (i, j) in ARISTAS) for x in 0:15]

function corte(gamma, beta)
    psi = ComplexF64[exp(-im * gamma * costo) / 4 for costo in COSTOS]
    c, s = cos(beta), sin(beta)
    for q in 0:3, x in 0:15
        (x & (1 << q)) != 0 && continue
        y = x | (1 << q)
        a, b = psi[x + 1], psi[y + 1]
        psi[x + 1] = c * a - im * s * b
        psi[y + 1] = c * b - im * s * a
    end
    return sum(abs2.(psi) .* COSTOS)
end

function buscar(pasos=80)
    mejor = (valor=-Inf, gamma=0.0, beta=0.0)
    for i in 0:pasos-1, j in 0:pasos-1
        gamma, beta = 2pi * i / pasos, pi * j / pasos
        valor = corte(gamma, beta)
        if valor > mejor.valor
            mejor = (valor=valor, gamma=gamma, beta=beta)
        end
    end
    return mejor
end

if abspath(PROGRAM_FILE) == @__FILE__
    println(buscar())
end
