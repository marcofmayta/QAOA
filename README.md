# QAOA en práctica: de las ecuaciones al código

Un proyecto educativo en español sobre el algoritmo de optimización aproximada cuántica (QAOA), creado por Marco Fidel Mayta Quispe. Conecta la formulación matemática con simulaciones interactivas, ejemplos de programación y ejercicios para explorar la optimización combinatoria cuántica.

El problema MaxCut sirve como hilo conductor: desde la construcción del Hamiltoniano de costo hasta la elección de ángulos, la evaluación del corte esperado y la comparación de implementaciones.

## Contenido

- **Fundamentos:** Hamiltonianos, evolución variacional, codificaciones QUBO–Ising y mezcladores.
- **Implementación:** ejemplos en Python con Qiskit, PennyLane, Cirq y NumPy, además de JavaScript y Julia.
- **Exploración interactiva:** paisaje del valor esperado, controles de ángulos, demostración de cortes y estimación aproximada de recursos.
- **Ejercicios:** dieciséis ejercicios con comprobación de respuestas y seis retos de programación.
- **Investigación y recursos:** criterios de evaluación, limitaciones del algoritmo, bibliografía y herramientas.
- **Sobre mí:** trayectoria académica y perfiles del autor.

## Alcance

Los ejemplos emplean simulación ideal de un ciclo de cuatro vértices. Ilustran las convenciones de signos, la estructura de las capas y la evaluación de resultados; no constituyen una demostración de ventaja cuántica. Las estimaciones de recursos son aproximadas y dependen de la conectividad y la compilación del circuito.

Las implementaciones de Qiskit, PennyLane, Cirq y NumPy se contrastaron numéricamente. El ejemplo de Julia todavía no cuenta con validación por ejecución.

## Tecnología

Sitio estático desarrollado con HTML, CSS y JavaScript. KaTeX presenta las ecuaciones y Prism resalta el código. GitHub Actions gestiona la publicación en GitHub Pages.
