Recursos

Enlaces a repositorios, conjuntos de datos, artículos y herramientas útiles para trabajar con QAOA a nivel de investigación.

Repositorios

  • OpenQAOA — API de alto nivel sobre múltiples entornos de ejecución (Qiskit, Braket, Rigetti).
  • PennyLane — biblioteca de programación cuántica diferenciable con módulo QAOA.
  • Qiskit — SDK de IBM con primitivas y tutoriales de QAOA.
  • Cirq — biblioteca de Google con ejemplos de QAOA.

Conjuntos de datos y evaluaciones comparativas

  • MQLib — biblioteca de heurísticas para MaxCut y QUBO con instancias estándar.
  • Para generar grafos 3-regulares o Erdős–Rényi, registrar el generador, el tamaño y la semilla. La biblioteca MQLib contiene instancias para comparación clásica.
  • Evaluaciones de QUBO: conjuntos de problemas en Biq Mac Library.

Artículos clave

  • Farhi, Goldstone, Gutmann (2014). Un algoritmo cuántico de optimización aproximada (título traducido). arXiv:1411.4028.
  • Hadfield et al. (2019). Del algoritmo cuántico de optimización aproximada a un ansatz de operadores alternantes (título traducido). arXiv:1709.03489.
  • Guerreschi, Matsuura (2019). QAOA para MaxCut requiere cientos de qubits para lograr aceleración cuántica (título traducido). arXiv:1812.07589.
  • Bravyi et al. (2020). Obstáculos para la optimización cuántica variacional por protección de simetría (título traducido). arXiv:1910.08980.
  • Barkoutsos et al. (2020). Mejora de la optimización cuántica variacional mediante CVaR (título traducido). arXiv:1907.04769.

Tutoriales y cuadernos de programación

  • Qiskit Optimization — módulo oficial con tutoriales.
  • Ejemplo de QAOA con PennyLane.
  • Tutoriales de Cirq.

Herramientas de comparación de rendimiento clásico

  • Gurobi — solucionador comercial de optimización entera mixta.
  • CPLEX — solucionador de IBM para programación entera mixta.
  • OR-Tools — suite de Google con solucionadores de rutas y asignación.
  • MQLib — heurísticas específicas para MaxCut/QUBO.
